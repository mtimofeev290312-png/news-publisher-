# Бесплатный GitHub-публикатор новостей

GitHub Actions запускает скрипт каждый час (в 17 минут после начала часа),
проверяет RSS трёх каналов и сам отправляет по одной новой новости в каждый.
Компьютер и сервер не нужны.

## Установка

1. Создайте на GitHub новый **Private** repository, например `news-publisher`.
2. Распакуйте архив и загрузите в корень репозитория обычные файлы:
   `channels.json`, `publish.py`, `requirements.txt`, `state.json`, `README_RU.md`.
3. Канал `@zumerinovosti` и три стартовых источника уже добавлены. Второй и
   третий канал добавляются позже отдельным объектом в `channels.json`.
4. Добавьте бота администратором в каждый канал, с правом публикации.
5. В GitHub: **Settings → Secrets and variables → Actions → New repository secret**.
   Имя: `TELEGRAM_BOT_TOKEN`; значение: токен от BotFather.
6. Создайте файл `.github/workflows/publish.yml` через **Actions → New workflow**
   и вставьте в него содержимое файла `workflow_publish.yml` из архива.
7. В GitHub: **Actions → Publish news → Run workflow → Run workflow**. Это
   проверит всё сразу, ждать час не нужно.

## Что важно

- Публикация идёт раз в час. Расписание GitHub может иногда сдвинуть запуск на
  несколько минут, но задача не прекращается через 15 минут и запускается снова
  каждый час.
- Английские RSS переводятся бесплатной офлайн-моделью EN→RU. Если модель или
  источник временно недоступны, исходный текст всё равно публикуется, а задача
  повторит проверку в следующий час.
- Это бесплатная автоматизация, поэтому редактура использует аккуратный формат,
  а не большой платный генеративный ИИ. Для полностью авторского пересказа нужен
  внешний ИИ-API или мощный постоянно работающий сервер.
